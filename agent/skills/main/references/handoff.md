# Execution Handoff

After exact delivery/publication, report the full Epoch/Batch/Iteration/lane,
base and tip, objective, actual tests, blockers and useful knowledge candidates.
Product candidates immediately enter [$batch](../../batch/SKILL.md) skill when
the controlling parent has the matching integration context. The candidate's
coding subagents do not integrate or publish.

Reuse an already supplied matching next context. Otherwise emit an exact
application assignment request with base, scope, objective, Exit Gate and checks.
Do not manufacture a branch, worktree, clone, application task or agent context.
A Batch close does not complete its milestone or advance Epoch.

`main.py step handoff --payload-json '{"assignment_request":"Exact next request"}'`
records only current-operation handoff and completes it. It neither schedules
external work nor changes Goal.
