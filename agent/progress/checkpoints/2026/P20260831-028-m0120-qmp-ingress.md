# M0120 W0122 QMP Ingress

## Outcome

`QmpLifecycleAdapter::complete_and_submit` now snapshots the pending event,
completes command/event correlation, converts a failed remove to the existing
`QmpFailure` event, and submits it through `submit_external_event`. The
correlation result (`QmpResult`) remains separate from the Coordinator's
authoritative `ResultDetails`, so duplicate and loss outcomes are observable
without adding QMP-specific authority state.
