# M0110 W0112 Queue Krefs

## Outcome

The cdev queue backing now has an explicit reference graph. The online root,
queue owner, worker lease, each queue VMA, and active wait/poll operation each
hold a `kref`. Offline transition drops the root reference; owner and lease
release drop their own references; module exit clears the corresponding file
flags before dropping them; and the final reference releases the mapping. This
keeps retained VMAs and in-flight wait/poll reads safe during owner close and
module teardown without changing the M0110 UAPI records.
