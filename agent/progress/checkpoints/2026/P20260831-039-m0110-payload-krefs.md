# M0110 W0112 Payload Krefs

## Outcome

The cdev payload arena now has an explicit reference graph. The online root,
data-file owner, each payload VMA, and the active `MEMORY_ALLOC`
copy-to-user operation each hold a `kref`. Offline transition drops the root
reference; owner close, copy failure, and module exit drop the owner reference;
and the final reference releases the vmalloc backing. Retained VMAs and an
in-flight allocation therefore remain safe across owner close and module
teardown without changing the M0110 UAPI records.
