# M0110 W0112 cdev DMA Mapping Checkpoint

## Outcome

The local cdev `MEMORY_REGISTER` path now maps its generation-bound SG table
through the data cdev's DMA device after pinning and SG construction. READ-only,
WRITE-only, and combined directions select `DMA_TO_DEVICE`,
`DMA_FROM_DEVICE`, and `DMA_BIDIRECTIONAL` respectively. A missing DMA device or
zero mapped-segment result is rejected before publication. Unregister, owner
close, module exit, and all map-failure paths unmap before SG teardown,
device-write dirtying, unpin, memlock release, and `mmput`.
